# Sistema de Historia Clínica Ginecológica

Aplicación web diseñada para la gestión clínica y seguimiento médico de pacientes ginecológicas y obstétricas.
Con esta app estoy iniciándome en el mundo de la programación con python.

## ¿Qué hace la aplicación?

- **Gestión de Pacientes**: Registro, edición y búsqueda de pacientes con datos demográficos, antecedentes médicos, ginecológicos y obstétricos.
- **Historial de Consultas**: Registro cronológico de consultas con examen físico, diagnóstico, tratamiento e indicaciones.
- **Estudios y Archivos**: Carga, visualización y gestión de estudios médicos adjuntos (PDFs, imágenes).
- **Acceso Seguro**: Control de acceso mediante autenticación de usuarios.
